# Chrome Web Store listing

Moved. The listing copy now lives in [`../store/LISTING.md`](../store/LISTING.md),
next to the images it describes, so the text and the assets cannot drift apart.

`store/` holds:

| | |
|---|---|
| `LISTING.md` | every field the Developer Dashboard asks for, ready to paste |
| `screenshots/` | five 1280x800 captures, produced by the end-to-end harness |
| `promo/` | the 440x280 tile, the 1400x560 marquee, and the 128x128 store icon |

The screenshots are real output from the real extension, generated by
`node test/e2e/run.mjs --market --shots store/screenshots`. Regenerate them rather
than editing them, so a listing image can never show an interface that no longer
exists.
