OpenFullPage settings

Everything here is off by default. Nothing is stored anywhere but this browser.

Advanced access

Extra ability that costs a permission. Chrome will ask you before granting it, and you can revoke it here at any time.

What this costs: access to every site you visit. Chrome has no narrower way to read inside a frame served by another domain, so it asks for all of them. What it does not change: the extension still cannot send anything anywhere. Its content security policy sets connect-src 'none', which Chrome enforces whatever permissions are granted.

While capturing

Appearance

How the editor and this page look. The same choice sits on the editor toolbar as a button that rotates through the three.

Theme Following your system is the default, and it keeps following it: if your computer switches to dark in the evening, so does this.

Toolbar

Which controls appear in the editor. Hiding one never disables its keyboard shortcut, and the settings button always stays.

Shapes

Which shapes appear behind the Shapes chevron. All twelve ship on. Turning the whole Shapes button off is one section above; this is for pruning the list to the ones you actually draw.

Your settings as a file

Settings are never synced, so they do not follow you to another computer on their own. Export them and you can carry them yourself, read them first, and import them anywhere.

A small .json file you can open in any text editor. On import, anything it contains that is not a setting we recognise is ignored, and every value is checked against the range it is allowed to hold.
